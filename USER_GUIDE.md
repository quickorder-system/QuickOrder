## Getting Started

### What is QuickOrder?

QuickOrder is a fast and convenient food ordering application that allows you to:
- Browse a wide variety of food items
- Place orders from your home
- Apply discount codes for savings
- Track your orders in real-time
- Manage multiple delivery addresses
- View your complete order history

### System Requirements

**Mobile/Tablet:**
- iOS 12+ or Android 8+
- Internet connection (WiFi or 4G)
- 50 MB available storage

**Desktop/Web:**
- Chrome, Firefox, Safari, or Edge (latest version)
- Minimum resolution: 1024x768
- Internet connection

### First Time Setup

1. **Download/Access the App**
   - Visit: https://quickorder.railway.app
   - Or download from your phone's app store

2. **Create an Account**
   - Click "Register" button
   - Enter your email address
   - Create a strong password (minimum 6 characters)
   - Enter your full name
   - Add your phone number (optional but recommended)

3. **Verify Your Email**
   - Check your email inbox
   - Click the verification link sent by QuickOrder
   - Your account is now active!

4. **Add Your First Address**
   - Add your home or work address
   - Mark it as default
   - You're ready to order!

### Profile Management

#### View Your Profile

**Option 1: Desktop**
- Click your name in the top-right corner
- Click "My Profile"

**Option 2: Mobile**
- Tap menu icon (≡)
- Tap "Profile"

**Your Profile Shows:**
- Full name
- Email address
- Phone number
- Email verification status
- Account creation date
- Last login time

#### Update Your Profile

1. Click "Edit Profile"
2. Update any of these fields:
   - Full Name
   - Phone Number
   - Notification Preferences
3. Click "Save Changes"

#### Change Your Password

1. Go to Profile
2. Click "Change Password"
3. Enter your current password
4. Enter your new password (minimum 6 characters)
5. Confirm new password
6. Click "Update Password"

**Tips for Strong Passwords:**
- Use at least 6 characters
- Mix uppercase and lowercase letters
- Include numbers and symbols
- Avoid common words or birthdays
- Never share your password

### Password Reset

**If You Forgot Your Password:**

1. Click "Forgot Password?" on login page
2. Enter your email address
3. Click "Send Reset Email"
4. Check your email (in 5 minutes)
5. Click the reset link
6. Enter your new password
7. Click "Reset Password"

**If You Don't Receive Email:**
- Check spam/junk folder
- Wait 5-10 minutes
- Try again with different email

## Ordering

### Browsing the Menu

#### View Menu

**Desktop:**
1. Click "Menu" in top navigation
2. Browse all items
3. Scroll or search for specific items

**Mobile:**
1. Tap menu icon (≡)
2. Tap "Browse"
3. Scroll through items

#### Categories

Items are organized by type:
- **Burgers** - Beef, chicken, veggie burgers
- **Pizza** - Various sizes and toppings
- **Sides** - Fries, salads, sides
- **Desserts** - Cakes, ice cream, etc.
- **Beverages** - Drinks and shakes
- **Combos** - Special meal packages

#### Filter & Search

**By Category:**
1. Click/tap category name
2. View items in that category

**Search:**
1. Click/tap search icon
2. Type item name
3. Results appear as you type

**Sort:**
- Sort by price (low to high)
- Sort by price (high to low)
- Sort by rating
- Sort by popular

### Adding Items to Cart

**Step 1: Select Item**
- Click/tap on item card
- View item details, price, and description

**Step 2: Choose Quantity**
- Use + and - buttons to adjust quantity
- Default quantity is 1

**Step 3: Add to Cart**
- Click "Add to Cart" button
- Item added confirmation message appears
- Continue shopping or proceed to checkout

**View Your Cart:**
- Click/tap cart icon (🛒)
- See all items and total price
- Review before checkout

### Checkout Process

**Step 1: Review Cart**
- Check all items and quantities
- Review subtotal
- Look for special offers

**Step 2: Enter Discount Code (Optional)**
- If you have a coupon code, enter it
- Click "Apply Discount"
- Discount amount shown if valid
- If invalid, error message appears

**Step 3: Select Delivery Address**
- Choose from saved addresses
- Or add new address
- Mark as preferred if needed

**Step 4: Choose Payment Method**
Options available:
- **Cash on Delivery** - Pay when order arrives
- **Card** - Debit or credit card
- **UPI** - Digital payment (available in India)
- **Mobile Wallet** - Google Pay, PhonePe, etc.

**Step 5: Review Order**
- Verify all items
- Confirm address
- Check total amount
- Review discount applied

**Step 6: Place Order**
- Click "Place Order"
- Confirmation message displays
- Order number shown
- Confirmation email sent

**Order Confirmation Includes:**
- Order number
- Items ordered
- Delivery address
- Estimated delivery time
- Order total
- Payment confirmation

### Applying Discount Codes

#### Where to Get Discount Codes

- Email promotions
- Birthday discounts
- Referral codes
- Special campaigns
- App push notifications

#### How to Apply Discount

**During Checkout:**
1. On checkout page, find "Discount Code" field
2. Enter your code
3. Click "Apply Discount"
4. Discount amount appears
5. Total price updates

**View Discount Details:**
- Discount type (fixed rupees or percentage)
- Discount amount
- Applicable minimum order
- Expiration date
- Number of uses remaining

#### Discount Not Working?

**Possible Reasons:**
- Code expired
- Used maximum times allowed
- Order amount below minimum
- Code not applicable to your items
- Typo in code

**Solution:**
- Check expiration date
- Verify order amount
- Check spelling
- Try different code
- Contact support

### Dietary Preferences

**Add Special Instructions:**
1. In checkout, find "Special Instructions"
2. Type your preferences:
   - "No onions"
   - "Extra spicy"
   - "No mayo"
   - "Vegan options only"

**Note:** Not all items can be customized  
**Confirmation:** Instructions sent to restaurant

## Order Management

### View Order History

**Desktop:**
1. Click your profile name
2. Click "Orders"
3. See all previous orders

**Mobile:**
1. Tap menu (≡)
2. Tap "Order History"
3. Scroll through orders

### Order Details

**Each Order Shows:**
- Order number (ORD-XXXX-XXXX)
- Order date and time
- Items ordered with quantities
- Delivery address
- Order status
- Total amount paid
- Payment method

### Order Status

**Order Statuses:**

1. **Pending** (⏳)
   - Order received
   - Being processed
   - Duration: 1-2 minutes

2. **Confirmed** (✓)
   - Order confirmed
   - Sent to restaurant
   - Duration: 1-2 minutes

3. **Preparing** (👨‍🍳)
   - Restaurant preparing your order
   - Duration: 15-30 minutes
   - Estimated time shown

4. **Ready** (📦)
   - Order ready for pickup
   - Out for delivery
   - Driver on the way

5. **Completed** (✓✓)
   - Order delivered
   - Delivery confirmed
   - Order complete

6. **Cancelled** (✗)
   - Order cancelled
   - Refund initiated
   - See cancellation reason

### Track Your Order

**Real-Time Tracking:**
1. Go to Order Details
2. See current status
3. Check estimated delivery time
4. View driver location (if available)
5. See step-by-step timeline

**Order Timeline Shows:**
- When order was placed
- When confirmed
- Preparation started
- Ready time
- Estimated delivery
- Actual delivery time

### Cancel Order

**Can You Cancel?**
- Yes, if order status is "Pending" or "Confirmed"
- Cannot cancel if "Preparing" or later
- Refund may take 3-5 business days

**How to Cancel:**
1. Go to Order History
2. Find order to cancel
3. Click "Cancel Order"
4. Select cancellation reason
5. Confirm cancellation
6. Refund initiated

**Refund Status:**
- Check your bank account
- Refund shows as "QUICKORDER REFUND"
- Processing time: 3-5 business days
- Credit back to original payment method

### Rate & Review

**After Order Complete:**
1. Order page shows "Rate Order" button
2. Click to open review
3. Rate 1-5 stars
4. Write comments (optional)
5. Click "Submit Review"

**Your Review Helps:**
- Restaurant improve service
- Other customers decide
- Us provide better recommendations

## Frequently Asked Questions

### Account & Login

**Q: I can't remember my password. What do I do?**
A: Click "Forgot Password" on login page. Enter your email and follow instructions sent to your mailbox.

**Q: Can I use multiple email addresses?**
A: Each email can only have one QuickOrder account. Contact support if you need to change email.

**Q: How do I delete my account?**
A: Go to Profile > Settings > "Delete Account". Your data will be permanently removed in 30 days.

**Q: My account was locked. Why?**
A: After 5 failed login attempts, account locks for 15 minutes for security.

### Orders

**Q: How long does delivery take?**
A: Average delivery time is 30-45 minutes, shown at checkout.

**Q: Can I modify my order after placing it?**
A: Only if order is still "Pending". Contact support immediately if needed.

**Q: I received wrong items. What should I do?**
A: Contact us through app or email with order number and photo. We'll resolve within 24 hours.

**Q: Can I schedule future orders?**
A: Coming soon! Currently only available for immediate orders.

**Q: Why is my order taking longer?**
A: Traffic, restaurant busy, or high volume. Check tracking for updates.

### Discounts

**Q: How do I get discount codes?**
A: Check email promotions, follow us on social media, or refer friends.

**Q: Can I combine multiple discount codes?**
A: No, only one discount per order.

**Q: My discount code doesn't work. Why?**
A: Check if it's expired, used all times, or order is below minimum.

**Q: When do birthday discounts apply?**
A: We send birthday codes via email in your birthday month.

### Payment

**Q: What payment methods are available?**
A: Cash on delivery, card, UPI, and mobile wallets.

**Q: Is my payment information safe?**
A: Yes, we use 256-bit encryption. Card info never stored.

**Q: Can I get an invoice/receipt?**
A: Yes, sent via email after order completes.

**Q: How do refunds work?**
A: Refunds take 3-5 business days to appear in your account.

### Addresses

**Q: Can I have multiple delivery addresses?**
A: Yes, add up to 5 addresses.

**Q: Can I edit address after placing order?**
A: No, you can't change address for current order. Contact support.

**Q: How is my address kept private?**
A: Your address is encrypted and only shown to authorized staff.

## Troubleshooting

### Common Issues & Solutions

#### App Crashes

**Problem:** App closes or freezes frequently

**Solutions:**
1. Restart your phone
2. Update app to latest version
3. Clear app cache:
   - Android: Settings > Apps > QuickOrder > Storage > Clear Cache
   - iOS: Delete and reinstall app
4. Check internet connection
5. Contact support if persists

#### Login Issues

**Problem:** "Invalid email or password" message

**Solutions:**
1. Check email spelling
2. Verify caps lock is off
3. Ensure password is correct
4. Try "Forgot Password" option
5. Contact support

**Problem:** "Too many login attempts"

**Solutions:**
1. Wait 15 minutes
2. Try again
3. Reset password if stuck

#### Ordering Issues

**Problem:** "Cart is empty" error

**Solutions:**
1. Add items to cart first
2. Check if items are available
3. Try refreshing page
4. Restart app

**Problem:** Checkout page won't load

**Solutions:**
1. Check internet connection
2. Try different browser
3. Clear browser cache
4. Update browser
5. Try mobile app instead

**Problem:** "Discount code invalid" when it should work

**Solutions:**
1. Check code spelling
2. Verify code hasn't expired
3. Check minimum order amount
4. Try different code
5. Contact support with code

**Problem:** Payment failed

**Solutions:**
1. Try different payment method
2. Check card has sufficient balance
3. Ensure card not expired
4. Check internet connection
5. Contact your bank if issue persists

#### Delivery Issues

**Problem:** Order not arriving

**Solutions:**
1. Check order status in app
2. Check address is correct
3. Call delivery partner (number in tracking)
4. Contact support with order number
5. Refund can be initiated if lost

**Problem:** "Delivery address outside service area"

**Solutions:**
1. Check if area is covered
2. Try different address
3. Check service area map in app
4. Contact support for availability

#### Account Issues

**Problem:** "Email not verified"

**Solutions:**
1. Check email inbox and spam
2. Look for verification link
3. Click link to verify
4. If no email received, request new link
5. Check email is correct

**Problem:** Can't add address

**Solutions:**
1. Fill all required fields
2. Check postal code format
3. Verify address exists
4. Try adding again
5. Contact support
